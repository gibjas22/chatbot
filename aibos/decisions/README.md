# Decisions

Settled decisions about the AIBOS Command Centre, one file each, named
`NNNN-short-slug.md` with a four digit sequence.

A decision belongs here when reversing it would cost real work: choice of
provider, data model, authentication approach, deployment target, naming
convention. Day to day implementation choices stay in `../conversations/`.

Each file should answer four questions:

1. **Context.** What was the situation that forced a choice.
2. **Decision.** What was chosen, stated plainly.
3. **Reasoning.** Why that option beat the alternatives that were considered.
4. **Consequences.** What this now commits us to, and what it rules out.

Do not delete superseded decisions. Mark them superseded and link forward to the
one that replaced them. The history of why something changed is often more
useful than the current state alone.
